# Publicação no GitHub Pages

Este pacote está configurado para o repositório `Portfolio` da conta `zapinhor`.

1. Copie todo o conteúdo deste pacote para a raiz do repositório e substitua os arquivos existentes.
2. Confirme que a pasta `.github/workflows` também foi copiada.
3. No GitHub Desktop, faça o commit e clique em **Push origin**.
4. No GitHub, abra **Settings → Pages**.
5. Em **Build and deployment → Source**, escolha **GitHub Actions**.
6. Abra a aba **Actions** e aguarde o fluxo “Publicar no GitHub Pages” terminar.
7. Acesse `https://zapinhor.github.io/Portfolio/`.

Os próximos envios para a branch `main` publicarão o site automaticamente.
