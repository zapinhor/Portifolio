# Portfólio — Danilo Petraglia

Versão estática do portfólio profissional, pronta para publicação gratuita no GitHub Pages.

## Como publicar

1. Crie um novo repositório público no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No repositório, acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch **main**, a pasta **/(root)** e clique em **Save**.
6. Aguarde alguns minutos. O endereço aparecerá nessa mesma página.

O site não precisa de instalação, compilação ou dependências. O arquivo principal é `index.html`.
